### Class B decisions `[ASSUMED]`

- **Linux App Service (`DOTNETCORE|10.0`).** The platform's own forwarded-header switch is turned off in IaC and refused by the Portal, so exactly one handler runs.
- **Single trusted hop.** If the platform front end appends its own entry, the right-most entry names the gateway rather than the client. The intake rate-limit partition then degrades to its credential/cookie component. It never trusts a client-supplied address. The live probe records which case applies.
- **Preserved host name.** The gateway presents the public host name on the backend leg, so the App Service needs that host bound with a certificate (`backendCertificateThumbprint`). Certificate issuance and Key Vault storage belong to the key slice.
- **Certificate-status allowlist.** The minimum set for the Microsoft and DigiCert chains. DEP-08 records any required addition, which is a reviewed change to the allowlist.
- **Azure Firewall Standard**, not Premium: no TLS inspection by construction.
- **Sticky sessions** (`clientAffinityEnabled`, gateway cookie affinity) for the Interactive Server circuit across two or more workers.
