## Pre-merge cleanup (human-requested 2026-10-01)

A narrow cleanup inside T06-owned and T06-amended files only. No region policy
changed: `PrimaryRegion = canadacentral`, `RecoveryRegion = canadaeast`,
AC-015, AC-131, DEP-03, the T01-T05 regional validators and allowlists, and
Document Intelligence's Canada Central pinning are untouched and remain a
separate PRD-level decision.

1. **Zone capability is explicit, not a region-name proxy.**
   `app-service.bicep`, `application-gateway.bicep` and `egress.bicep` take a
   required `param zoneRedundant bool`; the three `location == 'canadacentral'`
   tests are gone. `main.bicep` states the capability once per deployment role
   (`zoneCapability = { primary: true, recovery: false }`) and passes it to all
   six hosting module instances. The effective rule is unchanged: primary
   zonal, recovery non-zonal. `Test-ProductionPlan.ps1` now refuses
   (`ZoneRedundancyDisabled`) a module that hard-codes the value or compares
   `location` with a literal, a primary instance not bound to
   `zoneCapability.primary`, a recovery instance not bound to
   `zoneCapability.recovery`, and any change to the two stated capabilities.
2. **The Posture drill compares the configured recovery region.** The
   display-text comparison with `'Canada East'` is removed. `-Mode Posture`
   requires `-RecoveryRegion` (the `TaxAi:Production:RecoveryRegion` value),
   reads each failover partner's programmatic location from the server
   resource, and holds `FailoverPartnerInRecoveryRegion` only for exactly one
   partner whose location equals it. Without the parameter the mode is
   UNEXECUTED (exit 3).
3. **Role-based profile name.** The T06-introduced profile value
   `CanadaEastRecovery` is renamed `RegionalRecovery` (constant
   `RegionalRecoveryProfile`, `IsRegionalRecovery`). The PRD, architecture and
   every pre-T06 contract never used the literal; every consumer was a
   T06-owned or T06-amended file (both schemas, `runtime-configuration.bicep`,
   `main.bicep`, the validator/probe, both check scripts, the runbook and the
   tests). The value is still one of the 14 digest-covered recovery settings,
   so the signed-configuration digest input changes consistently everywhere.
   The T01 evidence item `CanadaEastRecoveryDrill` (DEP-18, in
   `ProductionControlModels.cs`, not T06-owned) is deliberately unchanged.
